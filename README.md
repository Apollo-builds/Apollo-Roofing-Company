# Apollo-Roofing-Company

Apollo Roofing is a roofing company template built on Whop Websites and live at apollo-roofing.whop.site. It has three real Whop plans: a $149 inspection fee, a $500 project deposit and a $395 flat-rate repair. The site reads live prices from the plans, so changing a price in Whop updates the site. Checkout uses only Whop Elements: the full CheckoutElement for card and financing methods, the ExpressCheckoutElement for Apple Pay and Google Pay, and the required BrandingElement. Klarna, Afterpay and Splitit financing shows automatically at checkout for approved merchants. The deposit flow first saves the customer's card on file with a Whop setup intent, which charges nothing, and then takes the deposit. The "Request an Estimate" form creates a lead through the Whop Leads API and stores the visitor's details in the lead's metadata. A passcode-protected admin page bills the final balance through the Whop Invoices API, either by auto-charging the stored card or by sending an invoice for manual payment. Custom whop.track events (estimate_requested, service_viewed, deposit_started) fire alongside Whop's automatic page-view and checkout tracking, and a ?debug=events panel shows them live. The whole template is configured from one file, so swapping the company name, services, prices or plan IDs needs no structural changes.
